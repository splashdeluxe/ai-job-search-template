# CV standard

Every tailored CV follows this. Deviations need the owner's say so.

- File: `Firstname_Lastname.pdf` with the owner's real name, 2 pages, in `cv/<Company>/` and, if used, Drive `CVs/<Company>/`.
- Photo: only if the owner's market expects one. Circular, top right. Headline never overlaps the photo.
- Headline: one line only, at most 3 role items, using the target role's title words, closest true title first. Never a title the owner has not held or cannot evidence.
- Header location: use the facts sheet block for the role's geography.
- Summary: first person (I, my), positive evidence only, strongest numbers in the first three lines. No gaps stated in the CV. Gaps go to the owner in the /apply brief.
- Experience: reverse chronological, newest first, always.
- Bullets: short, verb first, no subject. Hanging indent, tight bullet gap.
- Skills: page 2 section. No Core Skills block on page 1.
- Colours: dark ink body text, one muted accent, grey for dates and meta that still passes contrast at small sizes.
- Metric pass: after each build, list bullets with no hard number. Fix only with true numbers from the profile. Unknown numbers stay qualitative.
- Verify before use: page count is 2, text extraction order reads name, headline, summary, experience, and page 1 is checked visually.
